# BooksCollector

В проекте реализованы тесты для класса `BooksCollector`.

Проверяются следующие методы:

- `add_new_book` — добавление книги без жанра;
- `add_new_book` — запрет добавления книги длиннее 40 символов;
- `add_new_book` — запрет повторного добавления книги;
- `set_book_genre` — установка допустимого жанра;
- `get_book_genre` — получение жанра книги;
- `get_books_with_specific_genre` — получение книг выбранного жанра;
- `get_books_genre` — получение словаря всех книг и жанров;
- `get_books_for_children` — исключение книг с возрастным рейтингом;
- `add_book_in_favorites` — добавление книги в избранное без дубликатов;
- `delete_book_from_favorites` — удаление книги из избранного;
- `get_list_of_favorites_books` — получение списка избранных книг.
- `test_get_list_of_favorites_books_returns_favorites` — получение списка избранных книг: пустой список, одна книга и несколько книг.

## Фикстура

В файле `conftest.py` определена фикстура `collector`.
Она создаёт новый экземпляр `BooksCollector` для каждого запуска теста,
чтобы тесты не зависели друг от друга.

Для запуска тестов используется команда:
pytest -v tests.py
